# 食品包装/标签合规一体化排查与设计

## 概述

本技能把**法律（食品安全法）＋国标（GB 7718—2025）**两套依据合并为一个统一入口，支持两种典型用法：
1. **发图排查**：用户发送背标/标签截图 → 读图提取信息 → 逐项对照法律与国标排查 → **先给风险分级** → 再给修改意见。
2. **模糊提问**：用户用一句话提一个包装/标签问题 → 定位条款 → 排查 → 给出合规、正确、可执行、可落地的设计方案。

两种路径都遵循同一原则：**法律定底线与罚则，国标定技术细则，两层都满足才算可执行。**

## 参考文件（双依据）

- `references/food-safety-law.md` —— 食品安全法（草案）参考库：法定标示事项底线（74 条）、真实性红线（78 条）、商业宣传（80 条）、禁止经营（35 条）、特殊食品标签（81–91 条）、进口标签（118–128 条）、网络食品经营（100–110 条）、罚则（152/153/176/184 条）、违规整改对照表。
- `references/gb7718-2025.md` —— GB 7718—2025 参考库：核心数值门槛速查（20cm²/60cm²/25%/2%/6 个月/10%vol）、各主题条款要点、常见违规点速查。

## 路径一：发图排查（背标/标签截图）

1. **读图**：先下载图片到本地，用 `Read` 打开；设置足够大的 `thumbnail_size` 保证文字可辨认；文字过小或过密时分区域反复读取，确保提取完整。若图片为外链，先下载再读。
2. **提取标签要素**：逐项识别——食品名称、配料表、净含量/规格、生产日期/保质期到期日、贮存条件、生产者/经营者名称地址联系方式、许可证编号、产品标准代号、质量等级、致敏提示、营养信息、任何声称语（"零添加/不添加/天然/健康/供婴幼儿"等）。
3. **逐项排查**：对照 `food-safety-law.md`（法定事项是否齐全、是否真实、有无疾病预防/特定人群等红线）＋ `gb7718-2025.md`（日期格式、配料递减、定量标示、致敏、面积豁免等技术细则）。
4. **风险分级**（必做）：把发现的问题分三档——
   - **高风险（实质违法，建议立即整改）**：缺法定事项、虚假/疾病预防表述、标注虚假日期、无标签、属性与标签不符、特殊食品功能不实等 → 对应 152/153 条罚款、停业、吊销、惩罚性赔偿风险。
   - **中风险（需修改）**：配料排列、定量标示、致敏提示、声称用语等不符合国标细则 → 通常责令改正。
   - **低风险（瑕疵）**：不影响食品安全且不误导的小瑕疵 → 依 153 条2款责令限期改正。
5. **输出修改意见**：按风险从高到低列出"问题点 → 依据条款 → 修改建议（可直接落地的写法/做法）"。

## 路径二：模糊提问（一句话合规问题）

1. **定位主题**：判断问题属于食品名称/配料表/定量标示/日期/致敏/特殊食品/进口/网络/豁免等哪一类。
2. **双层检索**：先查 `food-safety-law.md` 定合法性与底线，再查 `gb7718-2025.md` 定技术细则；涉及面积/百分比/月数先核对数值门槛。
3. **排查并给方案**：给出"可执行 / 需修改 / 禁止"结论 + 依据条款 + 合规、正确、可直接落地的设计方案（含写法示例）。

## 回答结构（模板）

```
【结论】可执行 / 需修改 / 禁止 + 一句话理由。

【风险分级】（发图排查时必填；提问时若含风险点也填）
- 高风险：<问题> → 依据 <条款> → <后果>
- 中风险：<问题> → 依据 <条款>
- 低风险（瑕疵）：<问题> → 依据 <条款>

【法律依据】食品安全法（草案）第 X 条 要点。

【国标依据】GB 7718—2025 第 X 条 要点。

【修改意见 / 可落地方案】具体怎么改、怎么标才合规；给出可直接采用的字样、格式或写法示例。
```

## 示例问答（供理解口径）

**示例 A（发图排查）**：用户发来一张背标截图。
- 流程：读图 → 提取要素 → 排查 → 输出"高风险：标签未标生产许可证编号 → 依据食品安全法74条(八) → 属实质违法，建议立即补印；中风险：配料未按加入量递减排列 → 依据 GB7718 4.3.2 → 调整顺序；低风险：日期用了"见封口"但未标明部位 → 依据 GB7718 4.7.1 → 改为"见包装正面"。"

**示例 B（模糊提问）**：问"包装写『零添加防腐剂』可行吗？"
- 结论：需修改/禁止。
- 法律：78 条要求标签真实、不得引人误解；国标：GB7718 4.4.2.2 禁止"不添加/不使用"及其同义语（含"零添加"）。建议删除，如实标注配料。

## 边界

- 法律部分基于**征求意见稿**，引用标注"草案条款"，生效版本以全国人大常委会最终公布为准；技术细则以 GB 7718—2025 为准。
- 营养标签细则（按 GB 28050/GB 13432）、添加剂使用限量（按 GB 2760）只作引用提示，不深入展开。
- 不提供法律诉讼或个案执法结论；重要送检/上市前建议以标准原文、法律正式文本及监管部门意见为准。
