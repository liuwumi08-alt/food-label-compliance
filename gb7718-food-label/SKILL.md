# GB 7718—2025 预包装食品标签设计 / 审核问答

## 概述

本技能把 GB 7718—2025 全标准的强制条款、面积门槛、红线禁令和常见违规点整理成一份可检索的参考库。回答任何食品标签设计或商品审核疑问时，都以该参考库为权威依据，落到具体条款号，同时给出"可行做法"与"错误点/修改建议"两类答案。

## 参考文件

- `references/gb7718-2025.md` —— 唯一权威参考库。含：核心数值门槛速查（20 cm² / 60 cm² / 25% / 2% / 6 个月 / 10%vol）、适用范围与基本要求红线、按主题（食品名称、配料表、定量标示、净含量、日期、贮存、许可证、质量等级、致敏物质、营养标签、警示/辐照、非直接消费者、特殊食品、声称、进口、数字标签、豁免）整理的条款原文要点、常见违规点速查表。

## 问答流程（每次都必须按此执行）

1. **定位问题主题**：解析用户的标签设计/审核疑问，判定属于哪个主题域（食品名称、配料表、定量标示、净含量、日期、致敏物质、数字标签、进口、豁免、声称等）。若涉及"能否简化/能否用编码/能否省略某项"，先核对**包装物最大表面面积**（附录 C 算法，见参考库第 1 节）。

2. **定位条款**：在 `references/gb7718-2025.md` 中用关键词（Grep）检索对应主题，取出相关条款号、强制/可选项与红线。多个主题交叉时，逐一列出相关条款。

3. **给出可行设计**：基于条款允许的选项，给出具体的、可直接落地的设计做法（用什么引导词、按什么顺序、用什么形式、何时可豁免/简化），并给出与条款一致的示例。

4. **指出错误与红线**：明确指出用户方案中不符合标准的点、对应条款号、为什么违规、以及如何修改才可行。涉及"无/不含/不添加"声称、花式名称、特别强调未定量、日期加贴补印、致敏提示缺失等，必须明确点出。

5. **校验与口径**：核对面积门槛、百分比规则（25%、2%）、保质期月数（6 个月）、酒精度（10% vol）等数值是否符合；区分"强制（应）"与"鼓励/可标示（宜/可）"；若问题涉及营养标签（GB 28050）、添加剂使用（GB 2760）等配套标准，提示按对应标准执行，不越界展开。

## 回答结构（模板）

回答采用以下结构，保证可追溯、可直接用于整改：

```
结论：一句话给出"可行"或"不可行 + 关键违规点"。

依据条款：列出 GB 7718—2025 对应条款号并引用要点。

可行设计：给出符合条款的具体做法 + 示例（含引导词、顺序、格式、豁免条件）。

错误点（若适用）：逐条指出用户方案中的问题、对应条款、原因、修改建议。

校验项：数值门槛 / 强制vs可选项 核对结论。
```

## 边界

- 只依据 GB 7718—2025 及其配套提示（GB 28050、GB 13432、GB 2760、GB 14880 的引用关系）作答。
- 营养标签的具体标示细则、添加剂具体使用限量等，只提示按对应标准执行，不代为展开。
- 遇法律法规/标准更新或地方特殊规定，提醒用户以最新有效文本为准，本参考库基于 2025 版编制。

## 示例问答（供理解口径）

**问**：我的饼干想在包装上写"零添加防腐剂"，可以吗？
**答**：不可行。依据 4.4.2.2，"不添加""不使用"及其同义语（含"零添加""无添加"等，见 A.5.3）不得使用。防腐剂属法规不允许的禁止声称对象。可行做法：若确需强调，如实标示具体配料含量，避免任何"不添加"式表述。

**问**：包装特别强调"含 30% 果粒"，需要标含量吗？
**答**：需要。依据 4.4.1，特别强调添加或含有某配料成分，须在配料表明示或附加文字说明添加量或在成品中的含量；可用"≥30%""果粒含量 30%"等具体数值或百分比标示（A.5.1）。

**问**：我的复合配料（如"巧克力酱"）加入量是 30%，要怎么标配料？
**答**：加入量 ≥25% 且若无国标可据，须在配料表中标示"巧克力酱"，并在括号内按其原始配料递减顺序展开（4.3.3）。
